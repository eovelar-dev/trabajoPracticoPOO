# trabajoPracticoPOO
Una agencia de alquiler de vehículos posee un nombre, un conjunto de vehículos para alquilar, sus clientes y los alquileres realizados. 
Existen distintos tipos de vehículos, y cada uno tiene datos propios y una forma distinta de calcular el costo del alquiler.
Todos los vehículos pueden alquilarse, pero solamente los autos y las camionetas permiten contratar un seguro adicional. El seguro cuesta $8.000 por día en los autos y $12.000 por día en las camionetas. De cada alquiler se conoce el cliente, el vehículo, la cantidad de días y el costo total.
